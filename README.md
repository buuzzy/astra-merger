Astra 将双黑洞放在完全程序化生成的深蓝星空与银河带前：橙金色和冰蓝色旋转吸积盘、黑色视界与明亮光子环交织，旋近后出现沿波前折射星空的引力波涟漪，最终留下逐渐停止震荡的单一黑洞。直接用支持 WebGL2 的现代浏览器打开 index.html 即可；无需构建、外部库、字体、贴图或网络资源。拖拽环绕、滚轮或双指缩放，空格暂停，R 或“重新演化”重播；并合前后自动慢动作，右下角显示帧率、实际内部渲染比例和旋近／并合／铃宕阶段。

物理模型是视觉近似而非数值相对论：片元着色器逐像素自适应步长积分光线，以双中心引力偏折、视界捕获、光子球邻域发光和带多普勒增亮的体积吸积盘表现强引力透镜；轨道按衰减规律加速旋近，并在模拟时间 20 秒合并，随后指数衰减震荡，传播中的波壳扭曲程序化星场。requestAnimationFrame 驱动；模拟时间 17.2–22 秒使用 0.24 倍速度，长帧时间增量上限 0.05 秒；每条光线最多 168 步。内部尺寸基于 devicePixelRatio，像素预算为 2,400,000；质量档位从 0.30 到 1.00，高像素密度设备还会受像素预算限制；低于 50 FPS 降档，高于 58 FPS 回升，每 1.5 秒评估一次，调整后冷却 1.5 秒。页面包含着色器编译／链接错误提示、上下文丢失恢复，以及启动时在 48×32 离屏渲染缓冲上覆盖 0、19.5、20、24、32 秒的实际绘制自检；自检不等于真实 GPU 性能保证。
